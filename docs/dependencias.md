# backend
## instalar dependencias
Para inicializar el backend en se ejecuta el comando:

```
npm init
```

Luego de esto el ejecutable nos hara preguntas, y diligenciamos lo respestivo para luego instalar las dependencias de desarrollo.

```

npm install cors multer express mysql2
```
# frontend
## Crear un proyecto de React ´vite y que funcione a la primera se debe ejecutar el siguiente comando:

```
npm create vite@latest frontend -- --template react
```

Debe tener en cuenta que el nombre frontend es el nombre de la carpeta que en este caso contiene el proyecto REACT.
